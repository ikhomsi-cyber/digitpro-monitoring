# Product photographs

The complete public image mapping is in `carrefour-catalog.json`. Each entry retains its Carrefour product-page URL and original media URL. The 160-pixel local thumbnails live in `carrefour/`; image URLs remain available as a fallback when a thumbnail could not be downloaded. Product names without a confirmed match deliberately keep the generic placeholder. No email images are used.

The initial search examined 626 normalized titles from the imported history, followed by a second search for unmatched titles and targeted verification of October products. Package sizes may differ where the imported name omits the package size; the UI labels these images as illustrative.
